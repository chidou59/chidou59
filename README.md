## Principles

- Local first: experimental data and private documents should stay on the user's machine by default.
- Reproducible: repositories include setup instructions, dependency declarations, architecture notes, and automated checks.
- Honest limits: scientific predictions and third-party metadata always require human verification.

Bug reports and focused contributions are welcome. Please remove confidential research data, credentials, and personal information before opening an Issue.
